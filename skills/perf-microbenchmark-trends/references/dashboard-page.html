About this data

Each point is one run of the weekly microbenchmark job in the scylla-enterprise/perf-regression folder, taken from Argus result tables (Perf Simple Query, Perf CQL Raw and Perf Alternator, first row). The perf-alternator jobs started on 2026-11-22, so they have master runs only. A red ring means Argus marked that metric ERROR for the run. Runs that produced no result table are left out. Colors group runs by release line: master covers 2026.4.0~dev and 2027.1.0~dev, and 2026.4 covers the rc builds. Point at a run to see its full Scylla version; click it to open the run in Argus.

The data is a copy taken from Argus on 2026-11-22, covering the last three months. New runs appear only after the file is updated.
